# Plugin visual-system sources

This directory contains reviewable vector sources, tokens, and deterministic
export tooling. Generated PNGs live in `brand/build/` and are not committed.

The initial WP User Groups mark uses the `people` path from
`@wordpress/icons` 15.4.0 as its geometry reference. Gutenberg and its icon
sources are licensed under GPL-2.0-or-later; see the upstream package license.

Concept banners are proposals, not published WordPress.org assets. A reviewed
concept must be promoted deliberately before export into a plugin's Subversion
`assets` directory.
