# Support

For installation and usage questions, use the affected plugin's WordPress.org
support forum when the plugin is listed there and its forum accepts new topics,
or GitHub Discussions when the repository enables them. If neither is
available, use the GitHub issue tracker for those questions as well.

Use the GitHub issue tracker for reproducible defects and narrowly scoped
enhancements.

Security vulnerabilities must follow `SECURITY.md` and must not be reported in a
public venue, including an issue, pull request, discussion, or forum topic.
